# Changelog

All notable changes to the SanjanaIAS project will be documented in this file.

## [1.0.0] - 2026-11-11
### Added
- Initial production release of SanjanaIAS.
- Free daily UPSC current affairs (World, India, Telangana).
- Sanjana AI Tutor (Library-grounded).
- Prelims & Mains practice modules.
- User accounts, bookmarks, notes, and progress tracking via Supabase.
- AI & Search Engine discoverability (`llms.txt`, `ai.txt`, `robots.txt`).
- Vercel Edge Serverless rendering for Social Media & Bots (`api/render.js`).
- PWA Support with Offline Mode (`manifest.json`, `sw.js`).
